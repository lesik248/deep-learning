# Neural Networks Laboratory Assignments

This repository contains completed laboratory assignments for the Neural Networks course, implemented in Python using Pytorch, Scikit-learn, Pandas, Numpy.

## Contents

- **Lab 1. Function Approximation Using a Multilayer Perceptron** — training an MLP to approximate a given function, selecting the network architecture and training parameters, and evaluating performance using MAE and maximum error.
- **Lab 2. Time Series Forecasting** — training an MLP for time series forecasting using a sliding window, generating one-step-ahead and recursive forecasts, and evaluating performance using MAE and RMSE.
- **Lab 3. Object Classification** — training an MLP classifier, analyzing overfitting and applying regularization, and evaluating performance using accuracy and a confusion matrix.
- **Lab 4. Convolutional Neural Networks (CNNs)** — classifying synthetic images of geometric shapes, evaluating model performance, and visualizing feature maps.

## Technologies Used

- Python
- PyTorch
- NumPy
- Matplotlib
- scikit-learn

## How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open and run the corresponding notebook or Python file for each laboratory assignment.

## Project Goal

To study the main neural network architectures, their training principles, model evaluation methods, and result visualization techniques.
